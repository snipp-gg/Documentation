---
title: "List Public GIFs"
openapi: "api-reference/openapi.json GET /gifs"
---

Browse public GIFs across Snipp, newest first. No key required.

## Behavior

- Returns public posts whose first file is a `.gif`. Unlisted, private, draft, moderated, restricted and team posts are excluded, as are posts by suspended users.
- Each item is a full post object. `liked` is always `false`, since the request is anonymous.
- Results are [paginated](/concepts/pagination): pass `limit` (1 to 100, default 30) and the previous page's `next_cursor` as `cursor`.
- `search` matches the start of words in the title or description, case-insensitively. `kitt` matches "kitty" and "kitten" but not "skittle".
- Several words must all match, in any order. Up to 6 words are used.
- With a narrow `search`, a page can hold fewer than `limit` posts while `has_more` is still `true`. Keep following `next_cursor` until `has_more` is `false`.
- Rate limited per IP: 60 requests per minute.

## Examples

```bash
curl "https://api.snipp.gg/gifs?limit=50"
```

```bash
curl "https://api.snipp.gg/gifs?search=kitty%20cat"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Invalid `limit` or `cursor` |
| `429` | `rate_limited` | More than 60 requests per minute from your IP |
