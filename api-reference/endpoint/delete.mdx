---
title: "Delete Upload"
openapi: "DELETE /deleteUpload"
---

Delete a file from your account by filename.

## Behavior

- Pass the file's name in the `file` header. The filename is 32 hex characters plus an extension (for example, `a1b2c3d4e5f6789012345678abcdef01.png`). You can leave the extension off and the server finds the file.
- Get the filename from the `files[].fileName` field on [`GET /posts/{code}`](/api-reference/endpoint/post). [`GET /uploads`](/api-reference/endpoint/uploads) does not return a filename; take the last path segment of its `url` (before the `?` on a signed private URL).
- On a single-file post, deleting the file deletes the entire post.
- On an album, deleting a file removes just that file. Deleting the last remaining file deletes the album post.
- You can only delete your own uploads. A team key deletes its team's uploads instead.
- Files that belong to a moderated post cannot be deleted. The request returns `403` with `This post has been moderated and cannot be modified.` and nothing is removed.

## Examples

```bash
curl -X DELETE "https://api.snipp.gg/deleteUpload" \
  -H "api-key: YOUR_API_KEY" \
  -H "file: a1b2c3d4e5f6789012345678abcdef01.png"
```

## Responses

```json
{
  "message": "File deleted successfully."
}
```
