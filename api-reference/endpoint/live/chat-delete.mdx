---
title: "Delete Live Chat Message"
openapi: "api-reference/openapi.json DELETE /users/{id}/live/chat/{message_id}"
---

Remove a chat message.

## Behavior

- You can remove your own messages. They disappear for everyone with no placeholder. As on every chat route, a streamer who blocked you gives `403` with type `blocked`.
- The streamer, their moderators and staff can remove anyone's message. It stays in the chat as removed (`deleted: true`, `body: null`), and its text is gone for good.
- Anyone else gets `403` with type `forbidden`. A message that does not exist or was already removed gives `404`.

## Example

```bash
curl -X DELETE "https://api.snipp.gg/users/987654321098765432/live/chat/128" \
  -H "api-key: YOUR_API_KEY"
```
