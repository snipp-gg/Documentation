---
title: "Delete Live Stream"
openapi: "api-reference/openapi.json DELETE /live"
---

Turn streaming off: your stream key stops working and any broadcast in progress ends.

## Behavior

- Needs an API key with gallery access, like the gallery endpoints. Other keys get `403` with type `forbidden`. See [Authentication](/authentication).
- Minutes used by a broadcast in progress are charged before it ends.
- Your chat history, moderators and timeouts are kept, so setting up again later picks them back up.
- Returns `404` if streaming is not set up.

## Example

```bash
curl -X DELETE "https://api.snipp.gg/live" \
  -H "api-key: YOUR_API_KEY"
```
