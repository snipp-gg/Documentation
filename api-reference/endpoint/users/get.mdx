Fetch your own account (`@me`) or another user's profile.

## Behavior

- `@me` or your own ID returns your full account: every profile field plus `api_key`, `key_has_uploads_access`, `upload_count` and `limits`. `api_key` and `key_has_uploads_access` describe the key used for the request.
- Any other ID returns that user's public profile.
- `plan` is `free`, `plus` or `ultra`.
- `avatar` is always a URL. Users without an avatar get `https://cdn.snipp.gg/avatar.png`. `banner` is `null` when none is set.
- `bug_hunter_tier` is `0` (none), `1` (Bug Hunter) or `2` (Elite Bug Hunter).
- `following` and `blocking` are from your point of view: whether you follow or block that user. Both are `false` on your own profile.
- `limits.usage` is your weekly upload quota in bytes. `limits.priority_minutes` is your 30-day [priority minutes](/concepts/plans#priority-minutes) budget in minutes. `resets_at` is `null` if no window has been assigned yet.
- `limits.max_file_size` is the largest single file you can upload, in bytes.
- `upload_count` counts the files stored in your personal gallery.
- To list a user's posts, call [`GET /users/{id}/posts`](/api-reference/endpoint/users/posts).
- If the user is suspended, the response is `403` with type `suspended` and their `username`. This is checked before blocks.
- If the user has blocked you, the response is `403` with type `blocked`.
- Team keys are not accepted here and get `401`.

## Examples

Fetch your own account:

```bash
curl "https://api.snipp.gg/users/@me" \
  -H "api-key: YOUR_API_KEY"
```

Fetch another user:

```bash
curl "https://api.snipp.gg/users/987654321098765432" \
  -H "api-key: YOUR_API_KEY"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | `id` is not `@me` or a numeric ID |
| `401` | `unauthorized` | Missing or invalid key, or a team key |
| `403` | `suspended` | The user is suspended |
| `403` | `blocked` | The user has blocked you |
| `404` | `not_found` | No user with that ID |
