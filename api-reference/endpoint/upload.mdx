---
title: "Upload Files"
openapi: "api-reference/openapi.json POST /upload"
---

Upload between 1 and 50 files in one request. Every upload creates a post. Two or more files are grouped into one album post unless you ask for individual posts.

## Headers

| Header | Required | Description |
|--------|----------|-------------|
| `api-key` | Yes | Your API key, or a [team access key](/authentication#team-access-keys) |
| `post-privacy` | No | `public`, `unlisted` or `private`. Omitted means `private`. Any other value returns `400`. |
| `post-type` | No | `album` (default) or `individual`. Only matters for two or more files. |
| `include-metadata` | No | `true` keeps file metadata. Omitted or `false` strips it. |
| `priority` | No | `false` opts videos out of priority (adaptive) streaming. Omitted or `true` keeps it on, subject to your remaining priority minutes. |

Header values are trimmed and case-insensitive. Boolean headers accept only `true` or `false`; anything else returns `400`.

## Form fields

| Field | Required | Description |
|-------|----------|-------------|
| `file` | Yes | The file. Repeat the field for up to 50 files. |
| `title` | No | Up to 30 characters. Longer titles return `400`. |
| `description` | No | Up to 200 characters. Longer descriptions return `400`. |

## Behavior

- **One file:** creates one post. `post-type` is ignored.
- **Two or more files:** creates one album post, or one post per file with `post-type: individual`.
- **Response shape:** when one post is created the body is `{url, post}`, where `url` is the direct URL of the post's first file (`post.files[0].url`). When several posts are created (`individual`), the body is `{posts}`. An album where only one file survived also returns `{url, post}`.
- **`url` and `post.url`:** the top-level `url` is the direct file on `i.snipp.gg`. `post.url` is the share page, `https://snipp.gg/p/{code}`, or `https://{domain}/{code}` when the account has picked another [link domain](/concepts/custom-domains).
- **Private posts:** file URLs are signed and expire after 24 hours. Fetch the post again with [`GET /posts/{code}`](/api-reference/endpoint/posts/get) for fresh ones.
- **Videos:** `.mp4`, `.mov` and `.mkv` are remuxed to MP4 with `+faststart`, so `.mov` and `.mkv` come back with an `.mp4` name. A file that cannot be remuxed is rejected as corrupt. Uploaded videos get a thumbnail in `files[].thumbnail_url`. See [File Types](/concepts/file-types).
- **Metadata:** stripped by default. PNG, JPG, WebP and GIF are stripped at any size without re-encoding, so pixels are untouched; JPG and WebP keep their orientation and GIF keeps its animation. Videos lose container metadata during the remux.
- **Priority streaming:** eligible videos use adaptive streaming by default and spend [priority minutes](/concepts/plans#priority-minutes). `post.priority` is `true` when a video was queued for it. Minutes are charged after the response; if your budget runs out first, the video falls back to standard quality and the post later reports `priority: false`.
- **Partial failures:** files that fail are listed in `failed`, each with its zero-based `index` and an `error` object. The stored files are still returned with `200`.
- **Every file failed:** a one-file request returns that file's error at the top level, with `413` for `file_too_large`, `500` for `internal` and `400` otherwise. A request with several files returns `400` with type `upload_failed` and the same `failed` array. See [Errors](/concepts/errors#partial-upload-failures).
- **Weekly quota:** a file that would exceed your [weekly usage limit](/concepts/plans#weekly-usage-limit) fails with type `quota_exceeded`, carrying `quota`, `used` and `resets_at`.
- **Size limits:** a file over your plan's per-file limit fails with type `file_too_large`. A request whose declared `Content-Length` is already larger than your weekly quota (or 50 times the per-file limit) is refused with `413` before any file is read.
- **Team keys:** posts are always created `private`, whatever `post-privacy` says, and count against the team's quota. A lapsed team returns `403` with type `forbidden`.
- New posts are scanned automatically. A flagged post is moderated after the response.

## Examples

One file:

```bash
curl -X POST "https://api.snipp.gg/upload" \
  -H "api-key: YOUR_API_KEY" \
  -H "post-privacy: unlisted" \
  -F "title=my gaming POV" \
  -F "file=@screenshot.png"
```

An album:

```bash
curl -X POST "https://api.snipp.gg/upload" \
  -H "api-key: YOUR_API_KEY" \
  -H "post-privacy: public" \
  -F "title=Match highlights" \
  -F "file=@photo1.png" \
  -F "file=@photo2.png"
```

One post per file:

```bash
curl -X POST "https://api.snipp.gg/upload" \
  -H "api-key: YOUR_API_KEY" \
  -H "post-type: individual" \
  -F "file=@image1.png" \
  -F "file=@image2.png" \
  -F "file=@image3.png"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Bad header value, no file, more than 50 files, title or description too long, or a corrupt video |
| `400` | `unsupported_type` | The only file is not a supported type |
| `400` | `quota_exceeded` | The only file would exceed your weekly quota |
| `400` | `upload_failed` | Every file of a multi-file request failed |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | Your account, or the team owner's, is suspended |
| `403` | `forbidden` | The team's subscription has lapsed |
| `413` | `file_too_large` | The only file is over your limit, or the declared request size is |
| `429` | `rate_limited` | More than 20 uploads in 30 seconds |
| `500` | `internal` | The upload could not be saved |
