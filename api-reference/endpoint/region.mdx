---
title: "Get Region"
openapi: "api-reference/openapi.json GET /region"
---

Returns the region that served the request. Use it to confirm a regional endpoint, or to see where `api.snipp.gg` routed you.

## Behavior

- No key required and not rate limited.
- `region` is the region code, for example `eu-west-1` or `us-west-1`, or `unknown` when the server has none configured.
- `country` is the country for that region, or `null` when there is no mapping.
- `label` is a readable form such as `United Kingdom (eu-west-1)`, falling back to the bare region code.

## Examples

```bash
curl "https://api.snipp.gg/region"
```

```bash
curl "https://eu-west-1.api.snipp.gg/region"
```

## Responses

```json
{
  "region": "eu-west-1",
  "country": "United Kingdom",
  "label": "United Kingdom (eu-west-1)"
}
```
