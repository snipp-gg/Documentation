---
title: "Get Usage History"
openapi: "api-reference/openapi.json GET /usage-history"
---

Fetch your daily upload activity for the last 365 days, with summary stats. This is the data behind the Upload Activity heatmap on the Billing & Usage settings page.

## Behavior

- Returns activity for the key's owner only. Team keys get `401`.
- `history` is oldest first. Days with no uploads are left out, so the array is sparse.
- `bytes` and `upload_count` count successful uploads only.
- `stats.upload_count` and `stats.total_bytes` cover the whole 365-day window.
- `stats.current_streak` counts consecutive days with uploads ending today (UTC). It is `0` if you have not uploaded today.
- `stats.biggest_day` is `null` when there is no activity in the window.
- All days are UTC, formatted `YYYY-MM-DD`.

## Examples

```bash
curl "https://api.snipp.gg/usage-history" \
  -H "api-key: YOUR_API_KEY"
```

## Responses

```json
{
  "history": [
    {
      "day": "2026-09-28",
      "bytes": 5242880,
      "upload_count": 3
    },
    {
      "day": "2026-09-30",
      "bytes": 1048576,
      "upload_count": 1
    }
  ],
  "stats": {
    "total_bytes": 6291456,
    "upload_count": 4,
    "active_days": 2,
    "current_streak": 1,
    "biggest_day": {
      "day": "2026-09-28",
      "bytes": 5242880
    },
    "window_days": 365
  }
}
```

## Errors

| Status | Type | When |
|--------|------|------|
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | Your account is suspended |
| `429` | `rate_limited` | More than 30 requests per minute |
