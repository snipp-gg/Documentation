## Overview

Your link domain decides the domain on every post link you get from Snipp: the copy buttons on the site, `post.url` in API and Relay responses, ShareX and XerahS, and the Discord bot. Pick it in **Settings** under **Domains**.

Snipp's own domains, like `screenshott.ing`, are available on every plan. Connecting your own domain requires PLUS or Ultra.

| Link domain | Post link |
|-------------|-----------|
| `snipp.gg` (default) | `https://snipp.gg/p/{code}` |
| A Snipp domain, like `screenshott.ing` | `https://screenshott.ing/{code}` |
| Your own domain | `https://i.example.com/{code}` |

Every link domain redirects to `https://snipp.gg/p/{code}`, so the post always opens on Snipp and the address bar shows `snipp.gg` after the redirect. Every domain opens every post, and changing your link domain never breaks links you already shared.

## Connecting your own domain

Each account can connect one domain.

1. In **Settings** → **Domains**, enter a subdomain you own, like `i.example.com`, and click **Add Domain**.
2. Where your domain's DNS is managed, add a CNAME record:

| Type | Name | Target |
|------|------|--------|
| `CNAME` | `i.example.com` | `x.snipp.gg` |

If your DNS is hosted on Cloudflare, set the record's proxy status to **DNS only** (gray cloud).

3. Snipp checks the record and issues an HTTPS certificate for the subdomain. This usually takes a few minutes. Click the refresh button to check again.
4. Once the status shows **Active**, pick the domain as your **Link Domain**.

<Note>
Use a subdomain. Most DNS providers do not allow a CNAME record on a bare domain like `example.com`. If your DNS is hosted on Cloudflare, CNAME flattening makes a bare domain work too.
</Note>

Every path on a connected domain redirects to Snipp, so dedicate the subdomain to Snipp links. Keep the CNAME record in place: if it is removed, links on the domain stop working until it is restored, and a domain that stays unreachable is eventually disconnected.

Removing the domain in settings stops every link shared on it from working.

If your PLUS or Ultra plan ends, a link domain set to your own domain goes back to `snipp.gg`. Your domain stays connected for 30 days, so links already shared on it keep working, and you can pick it again if you resubscribe. After 30 days it is removed, and links shared on it stop working.

## API, Relay, and SDKs

There is nothing to configure. `post.url` in every API and Relay response, including uploads, uses the link domain of the account the key belongs to. Team keys always return `snipp.gg` links. A link domain change can take up to a minute to reach API and Relay responses.

ShareX and XerahS configs downloaded from Snipp copy `post.url`, so they pick up your link domain automatically. The top-level `url` on an upload, and `files[].url`, are direct file links on `i.snipp.gg` and are not affected.

<Warning>
A link domain changes how links look, not who can open a post. Anyone can open any Snipp post through any link domain, the same as through `snipp.gg`. Treat a custom domain as a vanity layer, not a security boundary.
</Warning>
