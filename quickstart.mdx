## Get Started in Three Steps

Make your first API call and upload a file to Snipp.

### Step 1: Get Your API Key

1. Sign in to your account.
2. Open **Settings**, go to **Console** and create an app.
3. Copy the app's API key. Include it in the `api-key` header with every request.

<Warning>
  Never share your API key or commit it to version control. Store it in an environment variable in production.
</Warning>

### Step 2: Verify Your Setup

Test your API key by fetching your own profile:

<CodeGroup>
```bash cURL
curl -X GET "https://api.snipp.gg/users/@me" \
  -H "api-key: YOUR_API_KEY"
```

```javascript JavaScript
const res = await fetch("https://api.snipp.gg/users/@me", {
  headers: { "api-key": "YOUR_API_KEY" },
});
const data = await res.json();
console.log(data.user.username);
```

```python Python
import requests

res = requests.get(
    "https://api.snipp.gg/users/@me",
    headers={"api-key": "YOUR_API_KEY"},
)
print(res.json()["user"]["username"])
```
</CodeGroup>

A successful response returns your account. It is trimmed here; see [Get User](/api-reference/endpoint/users/get) for every field.

```json
{
  "user": {
    "id": "123456789012345678",
    "username": "yourname",
    "plan": "free",
    "verified": false,
    "upload_count": 0,
    "limits": { ... }
  }
}
```

### Step 3: Upload a File

Upload an image or video to your account:

<CodeGroup>
```bash cURL
curl -X POST "https://api.snipp.gg/upload" \
  -H "api-key: YOUR_API_KEY" \
  -H "post-privacy: unlisted" \
  -F "file=@/path/to/image.png"
```

```javascript JavaScript
const formData = new FormData();
formData.append("file", fileInput.files[0]);

const res = await fetch("https://api.snipp.gg/upload", {
  method: "POST",
  headers: {
    "api-key": "YOUR_API_KEY",
    "post-privacy": "unlisted",
  },
  body: formData,
});
const data = await res.json();
console.log(data.url);
```

```python Python
import requests

with open("image.png", "rb") as f:
    res = requests.post(
        "https://api.snipp.gg/upload",
        headers={
            "api-key": "YOUR_API_KEY",
            "post-privacy": "unlisted",
        },
        files={"file": f},
    )
print(res.json()["url"])
```
</CodeGroup>

<Note>
  These examples use `api.snipp.gg`, which is the right host for production uploads too. It connects straight to the nearest upload server with no per-request size cap. Pin a regional endpoint such as `eu-west-1.api.snipp.gg` only when you want to control which region stores your files. See [Regional endpoints](/api-reference/introduction#regional-endpoints).
</Note>

The response includes the direct URL of your file and the post it created. `url` is the file itself; `post.url` is the share page. The post is trimmed here; see [Upload Files](/api-reference/endpoint/upload) for the full shape.

```json
{
  "url": "https://i.snipp.gg/123456789012345678/a1b2c3d4e5f6789012345678abcdef01.png",
  "post": {
    "code": "AbCd1234",
    "url": "https://snipp.gg/p/AbCd1234",
    "privacy": "unlisted",
    "file_count": 1,
    "files": [ ... ]
  }
}
```

If something goes wrong, the response has an `error` object with a `type` and a `message`. See [Errors](/concepts/errors).

### Albums

Upload multiple files in one request to create an album. Add additional `-F "file=@..."` fields:

```bash
curl -X POST "https://api.snipp.gg/upload" \
  -H "api-key: YOUR_API_KEY" \
  -F "title=My album" \
  -F "file=@photo1.png" \
  -F "file=@photo2.png"
```

Albums are the default when sending two or more files. To create separate posts instead, add `-H "post-type: individual"`.

### Privacy Options

Control who can see your uploads by setting the `post-privacy` header:

| Value | Visibility |
|-------|-----------|
| `private` | Only you, and anyone you have given access to, can view it (default). Response URLs are signed and expire after 24 hours. Re-fetch from `GET /posts/{code}` or `GET /posts` for a fresh link. |
| `unlisted` | Anyone with the share link can view it. |
| `public` | Visible to everyone and eligible for the Discover feed. |
