---
title: "Block User"
openapi: "relay-reference/openapi.json POST /users/{id}/block"
---

Block a user.

## Behavior

- The blocked user can no longer see your profile or posts, report you, or like and comment on your posts. Neither of you can follow the other, and Discover and comment lists hide each of you from the other.
- Blocking removes any follow between you, in both directions, and revokes access to private posts either of you had shared with the other.
- Blocking someone you already block succeeds and changes nothing.
- You cannot block yourself.
- Rate limited to 10 blocks per minute.

## Examples

```bash
curl -X POST "https://relay.snipp.gg/users/987654321098765432/block" \
  -H "relay-key: YOUR_RELAY_KEY"
```

## Responses

```json
{
  "blocking": true
}
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Invalid `id`, or yourself |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | Your account is suspended |
| `404` | `not_found` | No such user |
| `429` | `rate_limited` | More than 10 blocks per minute |
