---
title: "Unfollow User"
openapi: "relay-reference/openapi.json DELETE /users/{id}/follow"
---

Stop following a user.

## Behavior

- Unfollowing someone you do not follow succeeds and changes nothing.
- `follower_count` is the user's follower count after the call.
- To remove someone from your own followers, use [Remove Follower](/relay-reference/endpoint/users/remove-follower).
- Shares a rate limit bucket with Remove Follower: 30 requests per minute.

## Examples

```bash
curl -X DELETE "https://relay.snipp.gg/users/987654321098765432/follow" \
  -H "relay-key: YOUR_RELAY_KEY"
```

## Responses

```json
{
  "following": false,
  "follower_count": 12
}
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Invalid `id`, or yourself |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | Your account is suspended |
| `429` | `rate_limited` | More than 30 requests per minute |
