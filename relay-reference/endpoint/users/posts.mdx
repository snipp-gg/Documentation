---
title: "List User Posts"
openapi: "relay-reference/openapi.json GET /users/{id}/posts"
---

List a user's public posts, newest first. Use `@me` for your own.

## Behavior

- Only public posts are returned. Unlisted, private, draft, team, moderated and restricted posts never appear, including on `@me`. To list all of your own posts, use [`GET /posts`](/relay-reference/endpoint/posts/list).
- Results are [paginated](/concepts/pagination): pass `limit` (1 to 100, default 30) and the previous page's `next_cursor` as `cursor`.
- Each item is a full post object. `liked` is whether you have liked it. `moderated` and `restricted` only appear on your own posts.
- If the user is suspended, the response is `403` with type `suspended`. If the user has blocked you, it is `403` with type `blocked`.
- Shares a rate limit bucket with [`GET /posts/{code}`](/relay-reference/endpoint/posts/get).

## Examples

```bash
curl "https://relay.snipp.gg/users/987654321098765432/posts?limit=20" \
  -H "relay-key: YOUR_RELAY_KEY"
```

Next page:

```bash
curl "https://relay.snipp.gg/users/987654321098765432/posts?limit=20&cursor=eyJ0IjoiMjAyNi0wOS0yOFQxMDowMDowMC4wMDBaIiwiayI6IlF3RXI1Njc4In0" \
  -H "relay-key: YOUR_RELAY_KEY"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Invalid `id`, `limit` or `cursor` |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | The user is suspended |
| `403` | `blocked` | The user has blocked you |
| `404` | `not_found` | No user with that ID |
| `429` | `rate_limited` | Too many requests |
