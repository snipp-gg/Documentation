---
title: "Upload Avatar"
openapi: "relay-reference/openapi.json POST /users/{id}/avatar"
---

Upload a new avatar. `id` must be `@me` or your own ID.

## Behavior

- Send one image as `multipart/form-data` in the `file` field. More than one file returns `400`.
- PNG, JPG, WebP or GIF, up to **30 MB**. The type is detected from the file's bytes.
- The image is cropped to a centered square. GIFs stay animated.
- Metadata is stripped.
- The new avatar replaces the old one, which is deleted.
- A suspended account cannot upload a avatar.
- The response is your full account, with the new `avatar` URL.
- Shares a rate limit bucket with [Remove Avatar](/relay-reference/endpoint/users/delete-avatar): 10 requests per minute.

## Examples

```bash
curl -X POST "https://relay.snipp.gg/users/@me/avatar" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -F "file=@avatar.png"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | No file, or more than one |
| `400` | `unsupported_type` | Not a PNG, JPG, WebP or GIF |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `forbidden` | `id` is not you |
| `403` | `suspended` | Your account is suspended |
| `413` | `file_too_large` | Over 30 MB |
| `429` | `rate_limited` | More than 10 requests per minute |
