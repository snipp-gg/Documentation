---
title: "List Followers"
openapi: "relay-reference/openapi.json GET /users/{id}/followers"
---

List the users following a profile, most recent first. Use `@me` for your own.

## Behavior

- Each entry is a user with `following`: whether you follow that user back.
- Results are [paginated](/concepts/pagination): pass `limit` (1 to 100, default 30) and the previous page's `next_cursor` as `cursor`.
- Suspended users are left out after the page is read, so a page can hold fewer than `limit` users while `has_more` is `true`.
- If the profile's owner has blocked you, the response is `403` with type `blocked`.
- Shares a rate limit bucket with the other follow and block lists: 30 requests per minute.

## Examples

```bash
curl "https://relay.snipp.gg/users/987654321098765432/followers?limit=50" \
  -H "relay-key: YOUR_RELAY_KEY"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Invalid `id`, `limit` or `cursor` |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `blocked` | The user has blocked you |
| `403` | `suspended` | Your account is suspended |
| `429` | `rate_limited` | More than 30 requests per minute |
