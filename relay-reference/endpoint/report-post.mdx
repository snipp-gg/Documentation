Report a post for violating community guidelines. Reports are reviewed by the moderation team.

## Endpoint

### Report a Post

```
POST /report-post
```

Submit a report for a post using its share code. An optional reason can be provided to help moderators review the report.

**Request body:**

```json
{
  "code": "AbCd1234",
  "reason": "This post contains inappropriate content"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `code` | string | Yes | The share code of the post to report |
| `reason` | string | No | Reason for the report (max 200 characters) |

**Response:**

```json
{
  "success": true
}
```

## Errors

| Code | Error | When |
|------|-------|------|
| `400` | Missing or invalid post code. | `code` is empty or missing |
| `400` | Reason cannot exceed 200 characters. | `reason` exceeds 200 characters |
| `403` | Your account has been suspended. Reports are restricted. | Your account is suspended |
| `403` | This post has already been moderated. | The post has already been actioned by moderators |
| `403` | You cannot report your own post. | `code` belongs to a post you own |
| `403` | You cannot report this post. | The post author has blocked you |
| `404` | Post not found. | Post does not exist, is private or a draft, or is a team post |
| `429` | Rate limit exceeded. Please try again later. | Too many requests |

## Examples

Report a post:

```bash
curl -X POST "https://relay.snipp.gg/report-post" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "AbCd1234", "reason": "Inappropriate content"}'
```

Report a post without a reason:

```bash
curl -X POST "https://relay.snipp.gg/report-post" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "AbCd1234"}'
```

## Responses

```json
{
  "success": true
}
```
