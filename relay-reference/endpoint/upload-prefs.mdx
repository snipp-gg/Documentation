---
title: "Upload Preferences"
openapi: "POST /upload-prefs"
---

Read and update your account-wide upload preferences. These are the same settings as Preferences on the website and follow your account to every device. `GET` returns the current values, `POST` updates them.

## Behavior

- Send only the keys you want to change. Anything you leave out keeps its current value.
- `defaultPrivacy` is what the upload screen pre-selects. It does not change uploads that send their own privacy, and uploads that send none still default to private.
- `adaptiveStreaming` is on by default. The other toggles are off by default.
- An invalid `defaultPrivacy` or a non-boolean toggle returns `400` and nothing is saved.

## Examples

```bash
curl -X GET "https://relay.snipp.gg/upload-prefs" \
  -H "relay-key: YOUR_RELAY_KEY"
```

```bash
curl -X POST "https://relay.snipp.gg/upload-prefs" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"defaultPrivacy": "private", "autoCompress": true}'
```

## Responses

Both methods return the full set of preferences after the call.

```json
{
  "defaultPrivacy": "private",
  "adaptiveStreaming": true,
  "autoCompress": true,
  "includeMetadata": false,
  "autoCopyUrl": false
}
```
