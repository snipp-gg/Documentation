---
title: "List Comments"
openapi: "GET /comments"
---

List comments on a post. Pass the post's share code as the `code` query parameter.

## Behavior

- Returns each comment with the author's username, nickname, avatar, verified flag, and PLUS flag.
- `likes` is the total like count on the comment, and `liked` is whether you have liked it. Use [Like Comment](/relay-reference/endpoint/comment-like) to toggle.
- Comments from suspended users and from users you have blocked are filtered out.
- Drafts and moderated posts are visible only to the owner, private posts only to the owner and users given access, and team posts only to members of that team. Anyone else gets a `404`.

## Examples

```bash
curl -X GET "https://relay.snipp.gg/comments?code=AbCd1234" \
  -H "relay-key: YOUR_RELAY_KEY"
```
