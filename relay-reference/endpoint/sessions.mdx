---
title: "Sessions"
openapi: "GET /sessions"
---

List the devices signed in to your account on the website, and log them out. `GET` returns the list, `POST` logs devices out.

## Behavior

- Only website sign-ins are listed. Your relay key is a separate credential, so it never appears here and logging out sessions never affects it.
- `browser` and `os` are `null` for devices that cannot be recognized, including sign-ins from before device details were recorded. `type` falls back to `desktop`.
- `lastActive` is updated at most every 5 minutes.
- A logged-out device may keep working on the website for up to 30 seconds.
- Send `id` to log out one device, or `all: true` to log out every website session.

## Examples

```bash
curl -X GET "https://relay.snipp.gg/sessions" \
  -H "relay-key: YOUR_RELAY_KEY"
```

```bash
curl -X POST "https://relay.snipp.gg/sessions" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"id": "1768911a-e0f1-4705-9603-22ec8218e297"}'
```

```bash
curl -X POST "https://relay.snipp.gg/sessions" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"all": true}'
```

## Responses

`GET` returns the active sessions, most recently active first.

```json
{
  "sessions": [
    {
      "id": "1768911a-e0f1-4705-9603-22ec8218e297",
      "browser": "Chrome",
      "os": "macOS",
      "type": "desktop",
      "created": "2026-09-20T20:46:25.974Z",
      "lastActive": "2026-09-26T18:01:54.072Z"
    }
  ]
}
```

`POST` with `id` returns `{"message": "Device logged out."}`. With `all: true` it also returns how many were logged out.

```json
{
  "message": "All devices logged out.",
  "count": 2
}
```
