---
title: "Update Preferences"
openapi: "relay-reference/openapi.json PATCH /preferences"
---

Change any of your notification, email, upload and sharing preferences.

## Behavior

- Send a JSON body with only the sections and keys you want to change. Anything you leave out keeps its value.
- `notifications` accepts `follows`, `likes`, `comments` and `payouts`. `emails` accepts `payouts` and `sign_ins`. `uploads` accepts `default_privacy`, `adaptive_streaming`, `auto_compress`, `include_metadata` and `auto_copy_url`. `sharing` accepts `share_policy`.
- Every toggle must be a boolean. `uploads.default_privacy` must be `public`, `unlisted` or `private`. `sharing.share_policy` must be `everyone`, `following` or `nobody`.
- An unknown key or a wrong value returns `400` and nothing is saved.
- The response is the full set of preferences after the change. See [Get Preferences](/relay-reference/endpoint/preferences/get) for what each one does.
- Shares a rate limit bucket with Get Preferences: 20 requests per minute.

## Examples

```bash
curl -X PATCH "https://relay.snipp.gg/preferences" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"notifications": {"likes": false}, "uploads": {"default_privacy": "private"}}'
```

## Responses

```json
{
  "notifications": {
    "follows": true,
    "likes": false,
    "comments": true,
    "payouts": true
  },
  "emails": {
    "payouts": true,
    "sign_ins": true
  },
  "uploads": {
    "default_privacy": "private",
    "adaptive_streaming": true,
    "auto_compress": false,
    "include_metadata": false,
    "auto_copy_url": false
  },
  "sharing": {
    "share_policy": "everyone"
  }
}
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | An unknown key or an invalid value |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | Your account is suspended |
| `429` | `rate_limited` | More than 20 requests per minute |
