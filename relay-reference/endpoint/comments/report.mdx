---
title: "Report Comment"
openapi: "relay-reference/openapi.json POST /comments/{id}/report"
---

Report a comment to the moderation team.

## Behavior

- `reason` is optional. When sent it must be a string of at most 200 characters after trimming.
- You cannot report your own comment, a comment on a moderated post, or a comment whose author has blocked you.
- Comments on drafts, private posts you do not own, and team posts you are not a member of return `404`.
- You get a `report_received` notification confirming the report.
- Reports share one rate limit bucket with [post reports](/relay-reference/endpoint/posts/report) and [user reports](/relay-reference/endpoint/users/report): 3 per minute.

## Examples

```bash
curl -X POST "https://relay.snipp.gg/comments/0b7c4e2a-9f13-4d6b-8a21-5c3e7f9d1a04/report" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Harassment"}'
```

## Responses

```json
{
  "reported": true
}
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Invalid `id`, `reason` over 200 characters or not a string, or your own comment |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `moderated` | The post is moderated |
| `403` | `blocked` | The comment's author has blocked you |
| `403` | `suspended` | Your account is suspended |
| `404` | `not_found` | No such comment, or you cannot see its post |
| `429` | `rate_limited` | Too many reports |
