---
title: "Like Comment"
openapi: "relay-reference/openapi.json POST /comments/{id}/like"
---

Like a comment.

## Behavior

- Liking a comment you already like succeeds and changes nothing. `liked` and `like_count` are the state after the call.
- The comment's author gets a `comment_like` notification the first time you like it, unless they turned like notifications off.
- Comments on moderated posts return `403` with type `moderated`. If the comment's author has blocked you, the response is `403` with type `blocked`.
- Comments on drafts, private posts you do not own, and team posts you are not a member of return `404`.
- Shares a rate limit bucket with post likes: 30 requests per minute.

## Examples

```bash
curl -X POST "https://relay.snipp.gg/comments/0b7c4e2a-9f13-4d6b-8a21-5c3e7f9d1a04/like" \
  -H "relay-key: YOUR_RELAY_KEY"
```

## Responses

```json
{
  "liked": true,
  "like_count": 4
}
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | `id` is not a valid comment ID |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `moderated` | The post is moderated |
| `403` | `blocked` | The comment's author has blocked you |
| `403` | `suspended` | Your account is suspended |
| `404` | `not_found` | No such comment, or you cannot see its post |
| `429` | `rate_limited` | More than 30 likes per minute |
