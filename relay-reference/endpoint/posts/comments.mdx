---
title: "List Comments"
openapi: "relay-reference/openapi.json GET /posts/{code}/comments"
---

List a post's comments, oldest first.

## Behavior

- Returns every comment on the post in one response. A post holds at most 500 comments, so there is no pagination.
- Each comment carries its author as `user`, `like_count`, and `liked` (whether you liked it).
- Comments by suspended users are hidden. Comments by users you block, or who block you, are hidden too.
- You can list comments on any post you can see, including private posts shared with you. Drafts, private posts not shared with you, team posts you are not a member of, and posts by suspended users return `404`.
- Comments on a moderated post are only listed for its owner. Anyone else gets `404`.
- Not rate limited.

## Examples

```bash
curl "https://relay.snipp.gg/posts/AbCd1234/comments" \
  -H "relay-key: YOUR_RELAY_KEY"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | `code` is not a valid share code |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `suspended` | Your account is suspended |
| `404` | `not_found` | No such post, or you cannot see it |
