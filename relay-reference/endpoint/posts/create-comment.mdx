---
title: "Create Comment"
openapi: "relay-reference/openapi.json POST /posts/{code}/comments"
---

Comment on a post.

## Body

| Field | Type | Description |
|-------|------|-------------|
| `body` | string | The comment, 1 to 200 characters after trimming. |

## Behavior

- Longer comments return `400`; they are never truncated.
- A post holds at most **500 comments**.
- The post's owner gets a `comment` notification. Every `@username` in the comment gets a `mention` notification.
- Moderated posts return `403` with type `moderated`. If the author has blocked you, the response is `403` with type `blocked`.
- Drafts, private posts you do not own, team posts you are not a member of, and posts by suspended users return `404`.
- The response is the new comment.
- Shares a rate limit bucket with [Delete Comment](/relay-reference/endpoint/comments/delete): 5 requests per minute.

## Examples

```bash
curl -X POST "https://relay.snipp.gg/posts/AbCd1234/comments" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"body": "Nice shot!"}'
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | Empty or too long `body`, or the post is full |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `moderated` | The post is moderated |
| `403` | `blocked` | The author has blocked you |
| `403` | `suspended` | Your account is suspended |
| `404` | `not_found` | No such post, or you cannot see it |
| `429` | `rate_limited` | More than 5 requests per minute |
