---
title: "Add Files"
openapi: "relay-reference/openapi.json POST /posts/{code}/files"
---

Add one or more files to an existing post. The share code, privacy, title and description stay the same. Adding a file to a single-file post turns it into an album.

## Headers

| Header | Required | Description |
|--------|----------|-------------|
| `relay-key` | Yes | Your relay key, or the team's access key for a team post |
| `include-metadata` | No | `true` keeps file metadata. Omitted or `false` strips it. |
| `priority` | No | `false` opts the new videos out of priority (adaptive) streaming. |

Send the files as `multipart/form-data`, repeating the `file` field.

## Behavior

- You must own the post. A team post needs that team's access key, and a lapsed team returns `403`.
- Moderated posts cannot be changed and return `403` with type `moderated`.
- A post holds at most **50 files**. A full post, or a request that would go past 50, returns `400`.
- New files take the post's privacy. On a private post their URLs are signed and expire after 24 hours.
- Videos are remuxed to MP4 and metadata is stripped exactly as in [Upload Files](/relay-reference/endpoint/upload). Videos added here do not get a thumbnail.
- Each file is checked against your [weekly quota](/concepts/plans#weekly-usage-limit) on its own. A file that does not fit fails with type `quota_exceeded`.
- Failures work like uploads: stored files come back with `200` and the rest are listed in `failed`. If every file fails, a one-file request returns that file's error and a multi-file request returns `400` with type `upload_failed`. See [Errors](/concepts/errors#partial-upload-failures).
- New files are scanned automatically. If any file, or the post's text, is flagged, the whole post is moderated.
- The response is the full updated post.

## Examples

```bash
curl -X POST "https://relay.snipp.gg/posts/AlBm5678/files" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -F "file=@photo3.png"
```

## Errors

| Status | Type | When |
|--------|------|------|
| `400` | `invalid_request` | No file, too many files, a bad header value, or a corrupt video |
| `400` | `unsupported_type` | The only file is not a supported type |
| `400` | `quota_exceeded` | The only file would exceed your weekly quota |
| `400` | `upload_failed` | Every file of a multi-file request failed |
| `401` | `unauthorized` | Missing or invalid key |
| `403` | `forbidden` | Not your post, no gallery access, or a lapsed team |
| `403` | `moderated` | The post is moderated |
| `404` | `not_found` | No such post |
| `413` | `file_too_large` | The only file is over your per-file limit |
| `429` | `rate_limited` | More than 10 requests per minute |
