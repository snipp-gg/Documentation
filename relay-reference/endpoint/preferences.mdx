---
title: "Preferences"
openapi: "POST /preferences"
---

Read and update all of your account preferences in one place: notifications, emails and uploads. They follow your account to every device and match Preferences and notification settings on the website. `GET` returns the current values, `POST` updates them.

## Behavior

- Send only the sections and keys you want to change. Anything you leave out keeps its current value.
- `notifications` and `emails` work exactly as in [Notification Preferences](/relay-reference/endpoint/notification-prefs), which returns the same two sections without `uploads`.
- `uploads.defaultPrivacy` is what the upload screen pre-selects. It does not change uploads that send their own privacy, and uploads that send none still default to private.
- `uploads.adaptiveStreaming` is on by default. The other upload toggles are off by default.
- An invalid `uploads.defaultPrivacy` or a non-boolean upload toggle returns `400` and nothing is saved.

## Examples

```bash
curl -X GET "https://relay.snipp.gg/preferences" \
  -H "relay-key: YOUR_RELAY_KEY"
```

```bash
curl -X POST "https://relay.snipp.gg/preferences" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"uploads": {"defaultPrivacy": "private"}, "notifications": {"likes": false}}'
```

## Responses

Both methods return the full set of preferences after the call.

```json
{
  "notifications": {
    "follows": true,
    "likes": false,
    "comments": true,
    "payouts": true
  },
  "emails": {
    "payouts": true,
    "signIns": true
  },
  "uploads": {
    "defaultPrivacy": "private",
    "adaptiveStreaming": true,
    "autoCompress": false,
    "includeMetadata": false,
    "autoCopyUrl": false
  }
}
```
