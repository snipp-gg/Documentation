---
title: "Unfollow User"
openapi: "POST /unfollow"
---

Unfollow a user, or remove one of your own followers.

## Behavior

- Pass `target_id` to stop following that user.
- Pass `remove_follower` to remove that user from your own followers list. They will need to follow you again to see your posts in their feed.
- Exactly one of `target_id` or `remove_follower` must be provided. If both are present, `remove_follower` takes precedence.
- The ID must be numeric. A missing or non-numeric ID returns `400`.
- Unfollowing a user who is not followed succeeds without error.

## Examples

Unfollow a user you currently follow:

```bash
curl -X POST "https://relay.snipp.gg/unfollow" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"target_id": "123456789012345678"}'
```

Remove a follower:

```bash
curl -X POST "https://relay.snipp.gg/unfollow" \
  -H "relay-key: YOUR_RELAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"remove_follower": "123456789012345678"}'
```

## Responses

Unfollow:

```json
{
  "following": false
}
```

Remove follower:

```json
{
  "removed": true
}
```
